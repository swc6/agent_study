```bash

cd day17\mitigation_practice
```

## 示例代码

### 1. 幻觉抑制 (`anti_hallucination.py`)

展示如何通过提示词和检索增强来减少幻觉：
- 使用明确的反幻觉提示词
- 基于检索到的上下文生成回答
- 处理上下文无法回答的情况

**运行方法**：
```bash
python anti_hallucination.py
```

### 2. 引用溯源 (`citations.py`)

展示如何在生成回答时添加引用标记：
- 检索相关文档
- 构建带引用标记的上下文
- 生成带引用的回答
- 列出参考来源

**运行方法**：
```bash
python citations.py
```

### 3. 答案校验 (`validation.py`)

展示如何验证生成的回答是否准确：
- 生成回答
- 基于上下文校验回答
- 评估回答的准确性和完整性
- 提供校验结果和修正建议

**运行方法**：
```bash
python validation.py
```

## 核心概念

### 1. 幻觉抑制

幻觉是指智能体生成的内容与事实不符，或者包含不存在的信息。幻觉抑制是指通过各种方法减少或消除智能体生成的幻觉内容。

**主要方法**：
- 明确的提示词设计
- 基于检索增强的上下文
- 限制生成内容
- 多轮验证

### 2. 引用溯源

引用溯源是指在生成回答时，明确引用信息的来源，使用户能够验证信息的真实性。

**主要方法**：
- 直接引用原始文档
- 间接引用并标注来源
- 提供完整的来源信息

### 3. 答案校验

答案校验是指对智能体生成的回答进行验证，确保其准确性和可靠性。

**主要方法**：
- 基于模型的校验
- 基于规则的校验
- 基于外部知识的校验
- 多维度校验

## 最佳实践

### 1. 幻觉抑制

- **提供明确的提示词**：明确要求模型只基于上下文回答
- **使用高质量的检索结果**：确保检索到的文档与查询相关
- **限制生成长度**：避免模型生成过长的内容
- **使用温度参数**：降低温度参数，减少模型的创造性
- **多轮验证**：对重要的回答进行多轮验证

### 2. 引用溯源

- **明确的引用格式**：使用统一的引用格式
- **相关的引用**：确保引用与回答内容相关
- **简洁的引用**：避免过度引用
- **可靠的来源**：优先引用权威来源
- **完整的来源信息**：提供足够的来源信息

### 3. 答案校验

- **多层次校验**：使用多种校验方法
- **及时反馈**：及时提供校验结果和修正建议
- **持续改进**：根据校验结果改进系统
- **用户参与**：鼓励用户提供反馈
- **领域专家验证**：对关键领域的回答进行专家验证
