# 混合检索练习项目

本目录包含Hybrid混合检索（BM25 + 向量）的使用示例和实践代码，帮助你掌握混合检索的原理和应用。

## 环境准备

### 安装依赖

```bash
# 进入hybrid_practice目录
cd day9\hybrid_practice

# 安装依赖
pip install -r requirements.txt
```

## 示例代码

### 1. 基本混合检索 (`basic_hybrid_search.py`)

演示基本的混合检索功能：
- 加载BGE模型（支持本地模型）
- 构建BM25和向量索引
- 支持多种融合策略（线性、RRF、归一化）
- 比较不同融合方法的效果

**运行方法**：
```bash
python basic_hybrid_search.py
```

### 2. 带重排序的混合检索 (`hybrid_search_with_rerank.py`)

演示带重排序的混合检索功能：
- 集成BGE Rerank模型
- 先进行混合检索获取候选结果
- 使用Rerank模型对结果进行精排
- 比较带重排序和不带重排序的效果

**运行方法**：
```bash
python hybrid_search_with_rerank.py
```

## 学习路径

1. **基础篇**：运行 `basic_hybrid_search.py`，了解混合检索的基本原理
2. **进阶篇**：运行 `hybrid_search_with_rerank.py`，学习重排序的效果
3. **实践篇**：尝试修改参数，观察结果变化
4. **扩展篇**：将混合检索集成到实际应用中

## 学习建议

1. **理解核心原理**：
   - 混合检索的基本思想：结合BM25和向量检索的优势
   - 不同融合策略的原理和适用场景
   - 重排序的作用和实现方法

2. **参数调优**：
   - 调整alpha参数，观察对结果的影响
   - 尝试不同的融合方法，比较效果
   - 测试不同的top_k值，平衡召回率和精度

3. **性能分析**：
   - 测试不同数据量下的检索速度
   - 分析不同查询类型的效果
   - 评估内存使用情况

4. **实际应用**：
   - 构建简单的搜索引擎
   - 实现问答系统的文档检索
   - 开发推荐系统的内容匹配

## 常见问题

### 1. 模型加载失败
- 检查本地模型路径是否正确
- 确保网络连接正常（从Hugging Face下载）
- 检查磁盘空间是否充足

### 2. 检索速度慢
- 考虑使用更轻量级的模型
- 实现缓存机制
- 考虑使用批量处理

### 3. 检索结果不准确
- 调整alpha参数，平衡BM25和向量检索的权重
- 尝试不同的融合方法
- 考虑使用重排序模型

### 4. 内存使用过高
- 减少批量处理的大小
- 考虑使用模型量化
- 清理不必要的变量
