# 纯向量检索 + BM25 稀疏检索学习指南

## 1. 检索方法概述

在信息检索领域，主要存在两种检索方法：稀疏检索和稠密检索。每种方法都有其独特的原理和适用场景。

### 1.1 稀疏检索

**定义**：稀疏检索基于词频统计，使用稀疏向量表示文本，其中大多数维度的值为0。

**代表算法**：
- TF-IDF (Term Frequency-Inverse Document Frequency)
- BM25 (Best Matching 25)

**特点**：
- 基于词的精确匹配
- 计算速度快
- 对关键词敏感
- 不理解语义

### 1.2 稠密检索

**定义**：稠密检索使用预训练语言模型将文本转换为高维稠密向量，捕捉文本的语义信息。

**代表模型**：
- BERT
- BGE
- Sentence-BERT

**特点**：
- 基于语义理解
- 能够捕捉文本的深层含义
- 对同义词和语义相似性敏感
- 计算复杂度较高

## 2. BM25 稀疏检索

### 2.1 BM25 原理

BM25 (Best Matching 25) 是一种基于词频的排序函数，是TF-IDF的改进版本，广泛应用于信息检索系统。

**核心公式**：

```
score(d, q) = Σ [ IDF(t) * (f(t, d) * (k1 + 1)) / (f(t, d) + k1 * (1 - b + b * |d| / avgdl)) ]
```

**参数说明**：
- `score(d, q)`：文档d与查询q的相关性得分
- `IDF(t)`：词t的逆文档频率
- `f(t, d)`：词t在文档d中的频率
- `k1`：控制词频饱和度的参数（通常为1.2-2.0）
- `b`：控制文档长度归一化的参数（通常为0.75）
- `|d|`：文档d的长度
- `avgdl`：语料库中所有文档的平均长度

### 2.2 BM25 特点

- **词频饱和**：当词频达到一定程度后，得分增长会趋于平缓
- **文档长度归一化**：避免长文档获得过高的得分
- **逆文档频率**：稀有词具有更高的权重
- **简单高效**：计算速度快，适合大规模语料库

### 2.3 BM25 实现

**Python 实现**：

```python
from rank_bm25 import BM25Okapi

# 分词
corpus = [
    "人工智能的发展历史",
    "机器学习的基本原理",
    "深度学习的应用场景"
]
tokenized_corpus = [doc.split() for doc in corpus]

# 初始化 BM25
bm25 = BM25Okapi(tokenized_corpus)

# 搜索
query = "人工智能 原理"
tokenized_query = query.split()
scores = bm25.get_scores(tokenized_query)
docs = bm25.get_top_n(tokenized_query, corpus, n=2)
```

### 2.4 BM25 适用场景

- **关键词搜索**：用户查询包含明确的关键词
- **精确匹配**：需要精确匹配特定术语
- **大规模索引**：处理海量文档
- **实时搜索**：对响应速度要求高的场景

## 3. 纯向量检索

### 3.1 向量检索原理

纯向量检索使用预训练语言模型将文本转换为高维向量，然后通过计算向量之间的相似度来排序文档。

**核心步骤**：
1. **文本编码**：使用嵌入模型（如BGE）将文档和查询转换为向量
2. **向量存储**：将文档向量存储到向量数据库（如Milvus、FAISS）
3. **相似度计算**：计算查询向量与文档向量的相似度
4. **结果排序**：根据相似度对文档进行排序

### 3.2 相似度度量

**常用的相似度度量方法**：
- **余弦相似度**：衡量两个向量的方向一致性
- **欧氏距离**：衡量两个向量的空间距离
- **内积**：衡量两个向量的投影关系

### 3.3 向量检索特点

- **语义理解**：能够捕捉文本的深层语义
- **同义词识别**：能够识别语义相似的表达
- **上下文理解**：考虑词语在上下文中的含义
- **计算复杂度高**：需要大量的计算资源

### 3.4 向量检索实现

**Python 实现**：

```python
from sentence_transformers import SentenceTransformer
import numpy as np

# 加载模型
model = SentenceTransformer('BAAI/bge-base-zh-v1.5')

# 编码文档
documents = [
    "人工智能的发展历史",
    "机器学习的基本原理",
    "深度学习的应用场景"
]
doc_embeddings = model.encode(documents)

# 编码查询
query = "人工智能 原理"
query_embedding = model.encode([query])[0]

# 计算相似度
from sklearn.metrics.pairwise import cosine_similarity
similarities = cosine_similarity([query_embedding], doc_embeddings)[0]

# 排序
ranked_indices = np.argsort(similarities)[::-1]
ranked_docs = [documents[i] for i in ranked_indices]
```

### 3.5 向量检索适用场景

- **语义搜索**：需要理解用户查询的意图
- **模糊匹配**：用户查询表达不精确
- **跨语言搜索**：不同语言之间的搜索
- **长文档理解**：需要理解文档的整体含义

## 4. 两种检索方法的对比

| 特性 | BM25 稀疏检索 | 纯向量检索 |
|------|----------------|-------------|
| 原理 | 基于词频统计 | 基于语义理解 |
| 速度 | 快 | 较慢 |
| 准确率 | 对关键词敏感 | 对语义敏感 |
| 计算资源 | 低 | 高 |
| 适用场景 | 关键词搜索 | 语义搜索 |
| 处理能力 | 大规模文档 | 中等规模文档 |
| 理解能力 | 字面理解 | 语义理解 |
| 同义词识别 | 弱 | 强 |
| 上下文理解 | 弱 | 强 |

### 5.2 完整实现

```python
from sentence_transformers import SentenceTransformer
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

class VectorSearch:
    def __init__(self, model_name='BAAI/bge-base-zh-v1.5'):
        self.model = SentenceTransformer(model_name)
        self.documents = []
        self.embeddings = None
    
    def add_documents(self, documents):
        """添加文档并生成嵌入"""
        self.documents.extend(documents)
        new_embeddings = self.model.encode(documents)
        
        if self.embeddings is None:
            self.embeddings = new_embeddings
        else:
            self.embeddings = np.vstack([self.embeddings, new_embeddings])
    
    def search(self, query, top_k=5):
        """搜索相关文档"""
        query_embedding = self.model.encode([query])[0]
        similarities = cosine_similarity([query_embedding], self.embeddings)[0]
        
        # 排序
        ranked_indices = np.argsort(similarities)[::-1][:top_k]
        results = []
        
        for i in ranked_indices:
            results.append({
                'document': self.documents[i],
                'similarity': similarities[i]
            })
        
        return results

# 使用示例
if __name__ == "__main__":
    searcher = VectorSearch()
    
    # 添加文档
    documents = [
        "人工智能（Artificial Intelligence，简称AI）是研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统的一门新的技术科学。",
        "机器学习是人工智能的一个分支，它使计算机系统能够从数据中学习，而不需要被显式地编程。",
        "深度学习是机器学习的一个子集，它使用多层神经网络来模拟人脑的学习过程。",
        "自然语言处理是人工智能的一个领域，它使计算机能够理解、解释和生成人类语言。",
        "计算机视觉是人工智能的一个领域，它使计算机能够从图像或视频中提取有意义的信息。"
    ]
    
    searcher.add_documents(documents)
    
    # 搜索
    query = "什么是人工智能？"
    results = searcher.search(query, top_k=3)
    
    print(f"查询: '{query}'")
    for i, result in enumerate(results):
        print(f"{i+1}. 相似度: {result['similarity']:.4f}")
        print(f"   文档: {result['document']}")
```

### 6.1 环境准备

### 6.2 完整实现

```python
from rank_bm25 import BM25Okapi
import jieba

class BM25Search:
    def __init__(self):
        self.documents = []
        self.tokenized_corpus = []
        self.bm25 = None
    
    def add_documents(self, documents):
        """添加文档并构建索引"""
        self.documents.extend(documents)
        
        # 分词
        new_tokenized = [list(jieba.cut(doc)) for doc in documents]
        self.tokenized_corpus.extend(new_tokenized)
        
        # 重新构建BM25索引
        self.bm25 = BM25Okapi(self.tokenized_corpus)
    
    def search(self, query, top_k=5):
        """搜索相关文档"""
        if not self.bm25:
            return []
        
        # 分词
        tokenized_query = list(jieba.cut(query))
        
        # 搜索
        scores = self.bm25.get_scores(tokenized_query)
        
        # 排序
        ranked_indices = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)[:top_k]
        results = []
        
        for i in ranked_indices:
            results.append({
                'document': self.documents[i],
                'score': scores[i]
            })
        
        return results

# 使用示例
if __name__ == "__main__":
    searcher = BM25Search()
    
    # 添加文档
    documents = [
        "人工智能（Artificial Intelligence，简称AI）是研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统的一门新的技术科学。",
        "机器学习是人工智能的一个分支，它使计算机能够从数据中学习，而不需要被显式地编程。",
        "深度学习是机器学习的一个子集，它使用多层神经网络来模拟人脑的学习过程。",
        "自然语言处理是人工智能的一个领域，它使计算机能够理解、解释和生成人类语言。",
        "计算机视觉是人工智能的一个领域，它使计算机能够从图像或视频中提取有意义的信息。"
    ]
    
    searcher.add_documents(documents)
    
    # 搜索
    query = "什么是人工智能？"
    results = searcher.search(query, top_k=3)
```

## 7. 两种检索方法的评估

### 7.1 评估指标

**常用的评估指标**：
- **精确率 (Precision)**：检索结果中相关文档的比例
- **召回率 (Recall)**：所有相关文档中被检索到的比例
- **F1 分数**：精确率和召回率的调和平均值
- **平均准确率 (MAP)**：平均每个查询的准确率
- **NDCG**：归一化折扣累积增益，考虑结果的排序质量

### 7.2 评估方法

1. **准备测试集**：包含查询和对应的相关文档
2. **执行检索**：使用两种方法分别执行检索
3. **计算指标**：计算各种评估指标
4. **比较结果**：分析两种方法的优缺点

### 7.3 评估示例

```python
# 测试集
queries = [
    "人工智能的定义",
    "机器学习的应用",
    "深度学习的原理"
]

relevant_docs = [
    [0, 1],  # 第一个查询的相关文档索引
    [1, 2],  # 第二个查询的相关文档索引
    [2]      # 第三个查询的相关文档索引
]

# 执行评估
def evaluate(searcher, queries, relevant_docs, top_k=3):
    precisions = []
    recalls = []
    
    for i, query in enumerate(queries):
        results = searcher.search(query, top_k=top_k)
        retrieved_indices = [searcher.documents.index(result['document']) for result in results]
        
        # 计算精确率
        relevant_retrieved = set(retrieved_indices) & set(relevant_docs[i])
        precision = len(relevant_retrieved) / len(retrieved_indices) if retrieved_indices else 0
        precisions.append(precision)
        
        # 计算召回率
        recall = len(relevant_retrieved) / len(relevant_docs[i]) if relevant_docs[i] else 0
        recalls.append(recall)
    
    avg_precision = sum(precisions) / len(precisions)
    avg_recall = sum(recalls) / len(recalls)
    f1 = 2 * avg_precision * avg_recall / (avg_precision + avg_recall) if (avg_precision + avg_recall) else 0
    
    return {
        'precision': avg_precision,
        'recall': avg_recall,
        'f1': f1
    }

# 评估向量检索
vector_results = evaluate(vector_searcher, queries, relevant_docs)
print("向量检索评估结果:")
print(vector_results)

# 评估BM25检索
bm25_results = evaluate(bm25_searcher, queries, relevant_docs)
print("BM25检索评估结果:")
print(bm25_results)
```

## 8. 实际应用建议

### 8.1 选择合适的检索方法

**根据场景选择**：
- **关键词搜索**：使用 BM25
- **语义搜索**：使用向量检索
- **混合场景**：考虑混合检索（后续章节）

**根据数据特点选择**：
- **结构化数据**：使用 BM25
- **非结构化数据**：使用向量检索
- **大规模数据**：优先考虑 BM25

### 8.2 优化策略

**BM25 优化**：
- 调整 k1 和 b 参数
- 使用更精细的分词
- 考虑停用词过滤
- 实现倒排索引

**向量检索优化**：
- 选择合适的嵌入模型
- 使用向量数据库提高性能
- 考虑模型量化减少内存使用
- 实现批量处理提高效率

### 8.3 实际应用案例

**案例1：搜索引擎**
- 标题和关键词：使用 BM25
- 内容理解：使用向量检索
- 结果融合：综合两种方法的得分

**案例2：问答系统**
- 问题理解：使用向量检索
- 文档匹配：使用 BM25
- 答案提取：结合两种方法的结果

**案例3：推荐系统**
- 用户兴趣建模：使用向量检索
- 内容匹配：使用 BM25
- 推荐排序：综合考虑多种因素

## 9. 总结

纯向量检索和 BM25 稀疏检索各有优缺点，适用于不同的场景：

- **BM25 稀疏检索**：基于词频统计，速度快，对关键词敏感，适合精确匹配和大规模索引。
- **纯向量检索**：基于语义理解，能够捕捉文本的深层含义，对同义词和语义相似性敏感，适合语义搜索和模糊匹配。

在实际应用中，通常需要根据具体场景选择合适的检索方法，或者考虑将两种方法结合使用，以获得更好的检索效果。
