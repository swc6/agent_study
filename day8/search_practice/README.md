# 检索方法练习项目

本目录包含纯向量检索和BM25稀疏检索的使用示例和对比分析，帮助你理解两种检索方法的原理和应用。

## 环境准备

### 安装依赖

```bash
# 进入search_practice目录
cd day8\search_practice

# 安装依赖
pip install -r requirements.txt
```

## 示例代码

### 1. 纯向量检索 (`vector_search.py`)

演示使用BGE模型进行向量检索的功能：
- 加载BGE模型（支持本地模型）
- 生成文档和查询的向量表示
- 计算向量相似度
- 排序并返回结果

**运行方法**：
```bash
python vector_search.py
```

### 2. BM25 稀疏检索 (`bm25_search.py`)

演示使用BM25算法进行稀疏检索的功能：
- 对文档和查询进行分词
- 构建BM25索引
- 计算文档与查询的相关性得分
- 排序并返回结果

**运行方法**：
```bash
python bm25_search.py
```

### 3. 检索方法对比 (`search_comparison.py`)

对比两种检索方法的性能和效果：
- 使用相同的测试数据
- 执行相同的查询
- 评估精确率、召回率和F1分数
- 分析两种方法的优缺点

**运行方法**：
```bash
python search_comparison.py
```

## 学习路径

1. **基础篇**：运行 `vector_search.py`，了解向量检索的基本原理
2. **基础篇**：运行 `bm25_search.py`，了解BM25检索的基本原理
3. **对比篇**：运行 `search_comparison.py`，对比两种方法的效果
4. **实践篇**：尝试修改参数，观察结果变化
5. **扩展篇**：将两种方法集成到实际应用中

## 学习建议

1. **理解核心原理**：
   - 向量检索：基于语义理解，使用预训练模型生成向量
   - BM25检索：基于词频统计，使用TF-IDF的改进算法

2. **参数调优**：
   - 向量检索：尝试不同的嵌入模型，调整batch size
   - BM25检索：调整k1和b参数，尝试不同的分词方法

3. **性能分析**：
   - 测试不同数据量下的检索速度
   - 分析不同类型查询的效果
   - 评估内存使用情况

4. **实际应用**：
   - 构建简单的搜索引擎
   - 实现问答系统的文档检索
   - 开发推荐系统的内容匹配

## 常见问题

### 1. 模型加载失败
- 检查本地模型路径是否正确
- 确保网络连接正常（从Hugging Face下载）
- 检查磁盘空间是否充足

### 2. 分词效果不好
- 尝试使用更高级的分词工具
- 考虑添加自定义词典
- 处理停用词和标点符号

### 3. 检索速度慢
- 向量检索：考虑使用更轻量级的模型
- BM25检索：优化索引结构
- 考虑使用批量处理

### 4. 检索结果不准确
- 向量检索：尝试使用更大的模型或调整模型参数
- BM25检索：调整k1和b参数
- 考虑结合两种方法的优点

## 扩展实验

1. **不同模型对比**：测试不同的嵌入模型（如bge-small、bge-large）
2. **多语言测试**：尝试使用英文模型和英文文本
3. **长文档处理**：测试如何处理长文档的检索
4. **实时检索**：模拟实时添加文档的场景
5. **混合检索**：尝试结合向量检索和BM25检索的结果
