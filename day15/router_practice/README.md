# Agent 路由练习项目

本目录包含Agent路由的使用示例和实践代码，帮助你掌握Agent路由的核心技术。

## 环境准备

### 安装依赖

```bash
# 进入router_practice目录
cd day15\router_practice

# 安装依赖
pip install -r requirements.txt
```

### 配置环境变量

1. 创建`.env`文件，添加阿里云DashScope API密钥：
   ```
   DASHSCOPE_API_KEY=your_dashscope_api_key
   DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/api/v1
   ```

2. 本项目使用Qwen模型，通过阿里云DashScope API调用。

## 示例代码

### 1. 基础路由 (`basic_router.py`)

展示基于规则的路由功能：
- 使用关键词匹配识别意图

**运行方法**：
```bash

```

- 支持更多的意图类型
- 更准确的意图识别

**运行方法**：
```bash
python advanced_router.py
```

### 3. 与Agent集成的路由 (`agent_router.py`)

展示如何将路由与Agent集成：
- 基于意图选择合适的工具

**运行方法**：

## Agent 路由的核心概念

### 1. 什么是Agent路由？

Agent路由是指智能体根据用户的输入和对话上下文，决定如何处理请求的过程。它是智能体系统中的重要组成部分，能够根据不同的任务类型和用户意图，选择合适的处理路径。

### 2. Agent路由的价值

- **提高响应质量**：根据任务类型选择最合适的处理方法
- **优化资源利用**：避免不必要的计算和工具调用
- **提升用户体验**：为不同类型的请求提供定制化的响应
- **增强系统灵活性**：支持多种任务类型和处理流程

### 3. 路由方法

- **基于规则的路由**：使用预定义的规则和关键词进行匹配
- **基于意图识别的路由**：使用LLM识别用户的意图
- **基于机器学习的路由**：使用机器学习模型进行意图分类
- **混合路由**：结合多种方法进行路由

## 最佳实践

### 1. 意图识别

- **明确意图类型**：定义清晰的意图类型和边界
- **优化提示词**：设计有效的意图识别提示词
- **多轮确认**：对于模糊的意图进行多轮确认
- **持续优化**：从用户反馈中学习，不断改进意图识别

### 2. 路由策略

- **分层路由**：先进行粗粒度路由，再进行细粒度路由
- **上下文感知**：考虑对话历史，进行上下文感知的路由
- **动态调整**：根据处理结果动态调整路由策略
- **性能优化**：优化路由决策的速度和准确性

### 3. 处理逻辑

- **工具选择**：根据意图类型选择最合适的工具
- **错误处理**：处理路由错误的情况
- **用户反馈**：收集用户反馈，不断改进处理逻辑
- **可扩展性**：设计模块化的处理逻辑，支持新的意图类型
